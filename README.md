# NEXCHAT

A cross-platform real-time messaging platform.

## Stack

- Web: React + TypeScript + Vite
- API: Node.js + Fastify + Socket.IO
- Data: PostgreSQL + Prisma
- Cache and presence: Redis
- Desktop: Electron (planned)
- Mobile: React Native (planned)

## Development

Use `pnpm` workspaces. See `docs/architecture.md` and `apps/api/README.md`.
